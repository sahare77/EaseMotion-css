# Slide-Down Dropdown Menu

A classic dropdown menu enhanced with smooth CSS transitions for opacity and position.

### Usage
```html
<div class="dropdown">
  <button class="drop-btn">Options <span class="arrow"></span></button>
  <div class="drop-content">
    <a href="#">Edit</a>
    <a href="#">Duplicate</a>
    <a href="#">Delete</a>
  </div>
</div>
```

### Why is it useful?
This component provides a premium aesthetic and smooth micro-interaction that perfectly aligns with EaseMotion's framework-quality design standards. It relies entirely on CSS, making it performant and easy to integrate without JavaScript dependencies.
