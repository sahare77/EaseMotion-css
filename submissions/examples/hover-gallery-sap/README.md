# Hover-Reveal Image Gallery

An image gallery where hovering scales the image and smoothly reveals a gradient overlay and caption.

### Usage
```html
<div class="gallery">
  <div class="card"><img src="https://picsum.photos/400/300?random=1" alt="1"><div class="overlay">Image One</div></div>
  <div class="card"><img src="https://picsum.photos/400/300?random=2" alt="2"><div class="overlay">Image Two</div></div>
</div>
```

### Why is it useful?
This component provides a premium aesthetic and smooth micro-interaction that perfectly aligns with EaseMotion's framework-quality design standards. It relies entirely on CSS, making it performant and easy to integrate without JavaScript dependencies.
