# Shimmering Skeleton Loader

A loading placeholder component using an infinite linear gradient animation to simulate a shimmering effect.

### Usage
```html
<div class="skeleton-card">
  <div class="skeleton-avatar"></div>
  <div class="skeleton-lines">
    <div class="skeleton-line title"></div>
    <div class="skeleton-line desc"></div>
    <div class="skeleton-line desc short"></div>
  </div>
</div>
```

### Why is it useful?
This component provides a premium aesthetic and smooth micro-interaction that perfectly aligns with EaseMotion's framework-quality design standards. It relies entirely on CSS, making it performant and easy to integrate without JavaScript dependencies.
