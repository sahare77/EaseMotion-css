# Expandable Search Bar

A minimalist search button that expands into a full text input field on hover or focus.

### Usage
```html
<div class="search-box">
  <input type="text" class="search-input" placeholder="Search...">
  <button class="search-btn">🔍</button>
</div>
```

### Why is it useful?
This component provides a premium aesthetic and smooth micro-interaction that perfectly aligns with EaseMotion's framework-quality design standards. It relies entirely on CSS, making it performant and easy to integrate without JavaScript dependencies.
