# Rotating Border Card

A card component featuring a CSS conic-gradient animation simulating a glowing rotating border upon hover.

### Usage
```html
<div class="card-wrapper">
  <div class="card-content">
    <h2>Premium Card</h2>
    <p>Hover me to see the rotating border effect.</p>
  </div>
</div>
```

### Why is it useful?
This component provides a premium aesthetic and smooth micro-interaction that perfectly aligns with EaseMotion's framework-quality design standards. It relies entirely on CSS, making it performant and easy to integrate without JavaScript dependencies.
