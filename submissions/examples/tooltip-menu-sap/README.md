# Interactive Tooltip Menu

A popover menu that reveals itself on hover with a smooth scaling and fading animation.

### Usage
```html
<div class="tooltip-container">
  <button class="menu-btn">Hover Me</button>
  <div class="tooltip-menu">
    <a href="#">Profile</a>
    <a href="#">Settings</a>
    <a href="#">Logout</a>
  </div>
</div>
```

### Why is it useful?
This component provides a premium aesthetic and smooth micro-interaction that perfectly aligns with EaseMotion's framework-quality design standards. It relies entirely on CSS, making it performant and easy to integrate without JavaScript dependencies.
