# Fold-out Navigation

A fold-out horizontal navigation menu triggered by a pure CSS checkbox hack.

### Usage
```html
<div class="nav-wrapper">
  <input type="checkbox" id="nav-toggle">
  <label for="nav-toggle" class="nav-btn">☰</label>
  <ul class="nav-list">
    <li><a href="#">Home</a></li>
    <li><a href="#">About</a></li>
    <li><a href="#">Work</a></li>
  </ul>
</div>
```

### Why is it useful?
This component provides a premium aesthetic and smooth micro-interaction that perfectly aligns with EaseMotion's framework-quality design standards. It relies entirely on CSS, making it performant and easy to integrate without JavaScript dependencies.
